### 📌 Overview

This repository implements a **fully custom neural network framework built from scratch using only NumPy**, with no deep learning libraries.

The project focuses on **methodological correctness, experimental rigor, and reproducibility**, and is evaluated on:

- **MONK datasets** — for binary classification and model selection validation  
- **CUP dataset** — for final testing and generalization assessment  

The experimental pipeline includes **validation-loss–driven model selection**, **multi-seed robustness analysis**, and **ensemble evaluation**, following best practices in scientific machine learning.
